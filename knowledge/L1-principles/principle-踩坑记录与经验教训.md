## 核心内容

### 原则陈述

最初尝试用 Reddit 的 `.json` 后缀（如 `reddit.com/r/SideProject.json`）直接获取 JSON 数据，但 Reddit 对无 User-Agent 的请求会返回 429 Too Many Requests，即使加了 UA 也有模糊的速率限制。

### 推导依据

外部数据源都有隐性频率围墙，缓存策略不应该在"被限流后"才加，而是在设计阶段就要内置。

### 行动指引

不是"开发时随便写写 mock，上线后自然就对了"——mock 数据是一种隐性契约，应该在数据层的类型定义中明确声明，最好用 JSON Schema 或 TypeScript 类型统一约束。
